# 📘 eslovari.ru — электронный словарь IT-английского

Веб-приложение для изучения IT-английского на **Django** (домен — **eslovari.ru**).
Состоит из двух частей:

- 🛠 **Панель наполнения** (`/admin/`, адрес можно спрятать). Здесь сотрудники
  добавляют слова вручную или загружают их пачкой из **Excel**.
- 🎓 **Сайт для учеников** (`/`). Словарь сразу на главной, тренажёр с тремя
  режимами, персональные словари, статьи на английском и избранное.

Дизайн: сине-голубые карточки с «лентами» и чёрные плашки-пилюли. Сайт
подстраивается под телефон и компьютер и сам включает тёмно-синюю тему,
если она выбрана в системе.

## 🚀 Быстрый старт (Windows)

### Способ 1 — автоматически (проще)

1. Установите **Python 3.11+** с [python.org](https://www.python.org/downloads/)
   (при установке поставьте галочку **«Add Python to PATH»**).
2. Дважды кликните **`setup.bat`**. Он установит зависимости, создаст `.env`
   со случайным секретным ключом и базу, загрузит демо-слова и попросит
   придумать логин и пароль администратора.
3. Дважды кликните **`run.bat`**. Сайт откроется по адресу <http://127.0.0.1:8000/>.

### Способ 0 — через Docker (самый воспроизводимый)

Если установлен **Docker Desktop**, сайт и база поднимаются одной командой:

```bash
docker compose up -d --build
```

Подробно — в **[ДОКЕР.md](ДОКЕР.md)**.

### Способ 2 — вручную (в терминале)

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python deploy\make_env.py           # создаёт .env со случайным SECRET_KEY
python manage.py migrate
python manage.py seed_data          # демо-слова, наборы и статьи (по желанию)
python manage.py createsuperuser    # логин/пароль администратора
python manage.py runserver
```

Откройте:
- <http://127.0.0.1:8000/> — сайт для учеников;
- <http://127.0.0.1:8000/admin/> — панель наполнения (вход через общую форму входа сайта).

Проверить, что всё работает (27 автотестов: регистрация, вход, 2FA, блокировки,
импорт Excel, приватность словарей):

```powershell
python manage.py test
```

## ✨ Что умеет сайт

**Для учеников:**
- 🔍 Словарь **сразу на главной** с поиском и фильтром по IT-темам, «слово дня».
- 🎯 **Тренажёр с тремя режимами** (кнопки прямо на главной):
  - 🃏 *Карточки*: листай и переворачивай (пробел, стрелки);
  - ❓ *Квиз*: выбери правильный перевод из четырёх (клавиши 1–4);
  - ⌨️ *Письмо*: напечатай английское слово сам (есть подсказка).

  Любой режим запускается по теме, набору, своему словарю или избранному.
  После тренировки показываются ошибки, а результат сохраняется в профиль.
- 📁 Персональные словари: свои темы со словами из общего словаря и своими словами.
- 📖 Статьи об IT на английском с уровнями (A1–C2).
- ⭐ Избранное: слова, наборы и темы.
- 👤 Профиль с аватаром, группой и соцсетями, статистикой и сменой пароля.
- 🔐 Вход с **защитой от подбора пароля** (django-axes) и
  **двухфакторной аутентификацией** (код из приложения и резервные коды).

**Для сотрудников (панель наполнения):**
- Добавление, редактирование и удаление слов, поиск и фильтры.
- 📥 **Импорт из Excel**: кнопка на странице «Словарные записи», там же шаблон.
- 📤 **Экспорт в Excel**: действие над выбранными записями.
- Управление тегами, наборами карточек и статьями.

### Формат Excel для импорта
Данные читаются со **второй строки** первого листа (первая — заголовки):

| Столбец | A | B | C | D |
|---|---|---|---|---|
| Содержимое | Английское слово | Русский перевод | Транскрипция | Описание (англ.) |
| Обязателен | да | да | нет | нет |

Строки без слова или перевода пропускаются. Если слово уже есть (без учёта
регистра), перевод и описание обновляются (это можно выключить галочкой).

## 🧱 Стек технологий

- **Python 3.11+**, **Django 5.2 (LTS, поддержка до апреля 2028)**
- **SQLite** по умолчанию (без настройки) → **PostgreSQL** для продакшена
- **openpyxl**: Excel, **python-decouple**: настройки через `.env`
- **django-axes**: защита входа, **django-otp + qrcode**: двухфакторная
  аутентификация, **social-auth-app-django**: вход через Яндекс
- **WhiteNoise**: статика, **Pillow**: картинки, **gunicorn + Caddy**: сервер и HTTPS
- Шрифты Manrope и Unbounded лежат в проекте, без внешних CDN

> В первоначальном плане был Django 4.2, но поддержка 4.2 закончилась в апреле
> 2026 года, и обновлений безопасности он больше не получает. Поэтому проект
> на **Django 5.2 LTS**.

### 🛡 Защита регистрации и входа (встроено, работает само)

- **Пароли хэшируются Argon2.** Даже при утечке базы восстановить пароли
  практически невозможно.
- **Правила паролей**: минимум 10 символов, обязательно буквы и цифры,
  проверка на слишком простые пароли, живой индикатор надёжности в форме.
- **Анти-бот регистрация**: скрытое поле-ловушка (honeypot), проверка времени
  заполнения формы (подписанная метка) и лимит «не более 5 регистраций с одного IP в час».
- **Служебные имена заняты**: нельзя зарегистрироваться как admin, support и т.п.
- **Вход по логину или email.** После 5 неверных паролей вход для этого
  аккаунта с этого IP блокируется на час.
- **«Запомнить меня»**: без галочки сессия живёт до закрытия браузера,
  с галочкой — 30 дней.
- **Показ даты предыдущего входа** в профиле: чужое посещение аккаунта сразу заметно.
- **Восстановление пароля по email**: «Забыли пароль?» на странице входа.
  Локально письма печатаются в консоль сервера; для продакшена заполните
  `EMAIL_*` в `.env` (пример для Яндекса есть в `.env.example`).
- **Скрываемый адрес админки**: задайте `ADMIN_URL=любой-адрес` в `.env`,
  и сканеры ботов не найдут панель на стандартном `/admin/`.
- **Обязательная 2FA для админки**: `ADMIN_REQUIRE_2FA=True` (на сервере включено).
- **Заголовки безопасности**: Content-Security-Policy (только свои скрипты),
  HSTS, запрет встраивания во фреймы, безопасные cookie.

### 🔐 Как включить двухфакторную аутентификацию (2FA)
1. Войдите на сайт → **Профиль** → кнопка **«Включить 2FA»**.
2. Отсканируйте QR-код приложением. Рекомендуем **Яндекс Ключ** (на русском,
   работает офлайн); подойдут и Google Authenticator, Microsoft Authenticator
   и любые другие (используется стандарт TOTP). На телефоне есть кнопка
   **«Открыть в Яндекс Ключе»**, она сама добавит код в приложение.
3. Введите 6-значный код. Сайт покажет **8 резервных кодов**,
   сохраните их: каждый работает один раз, если телефон потерян.
4. Теперь вход двухшаговый: пароль → код из приложения.
   Новые резервные коды и отключение 2FA — в профиле, с подтверждением паролем.

### 🟥 Как включить «Войти через Яндекс» (Yandex ID)
Одна кнопка, и пользователь входит или регистрируется через свой аккаунт Яндекса
(пароль и 2FA при этом обеспечивает сам Яндекс). Кнопка появляется автоматически,
когда в `.env` заданы ключи:
1. Откройте <https://oauth.yandex.ru> → **Создать приложение**.
2. Платформа — **«Веб-сервисы»**, Redirect URI:
   - локально: `http://127.0.0.1:8000/complete/yandex-oauth2/`
   - на проде: `https://eslovari.ru/complete/yandex-oauth2/`
3. Доступы: **«Доступ к адресу электронной почты»** и
   **«Доступ к логину, имени и фамилии»**.
4. Скопируйте **ClientID** и **Client secret** в `.env`
   (`YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET`) и перезапустите сайт.

> Аккаунт, созданный через Яндекс, связывается по Yandex ID и email; повторный
> вход узнаёт того же пользователя. Пароль такому аккаунту не нужен:
> вход всегда через кнопку Яндекса.

Вход в админку идёт **только через общий защищённый вход сайта**:
отдельной «двери» с формой пароля у админки нет.

## 📂 Структура проекта

```
eslovari-main/
├── manage.py                # управление проектом
├── requirements.txt         # список зависимостей
├── .env.example             # пример настроек (копируется в .env)
├── setup.bat / run.bat      # установка и запуск для Windows
├── Dockerfile               # образ сайта
├── docker-compose.yml       # локально: сайт + PostgreSQL
├── docker-compose.prod.yml  # сервер: сайт + PostgreSQL + Caddy (HTTPS)
├── deploy/                  # Caddyfile, entrypoint, backup.sh, make_env.py
├── README.md                # этот файл
├── ХОСТИНГ.md               # как выложить на Selectel и привязать домен
├── ДОКЕР.md                 # запуск через Docker
├── electronic_dictionary/   # настройки проекта (settings.py, urls.py)
└── dictionary/              # приложение
    ├── models.py            # словарь, теги, наборы, темы, статьи, профиль
    ├── views.py             # страницы для учеников
    ├── accounts.py          # регистрация, вход, 2FA
    ├── admin.py             # панель наполнения + импорт/экспорт Excel
    ├── admin_site.py        # вход в админку только через сайт
    ├── forms.py             # формы
    ├── tests.py             # автотесты
    ├── management/commands/seed_data.py  # демо-данные
    ├── templates/           # HTML-шаблоны
    └── static/              # CSS, JavaScript, шрифты
```
